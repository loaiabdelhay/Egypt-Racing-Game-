# Masr Racer — بداية مشروع لعبة سباق مصرية

نسخة أولية قابلة للتشغيل في المتصفح، فيها:
- مشهد 3D مولّد برمجياً بطريق مستوحى من شوارع القاهرة ومبانٍ ونهر النيل.
- سيارة قابلة للقيادة، كاميرا خلفية وكاميرا من داخل السيارة.
- أزرار لمس للموبايل + لوحة مفاتيح للكمبيوتر.
- حركة مرور تجريبية.
- أساس اتصال WebSocket لمزامنة مواقع اللاعبين.

## التشغيل محلياً
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000`.

## ملاحظات مهمة
- هذه Prototype وليست لعبة نهائية بمستوى AAA. المجسمات والمدينة حالياً procedural placeholders.
- زر "اتصال لاعب تاني" يفتح قناة WebSocket ويتبادل إحداثيات اللاعبين، لكن رسم سيارة اللاعب الآخر والاصطدامات والسباق التنافسي ما زالت خطوات تطوير لاحقة.
- Three.js يُحمّل من CDN، لذلك يلزم اتصال إنترنت.
- للنشر العام استخدم استضافة تدعم Node.js وWebSocket وHTTPS (مثل VPS أو Render/Fly.io)، وليس استضافة ملفات ثابتة فقط.
- للحصول على جودة عالية حقيقية نحتاج موديلات سيارات وبيئات محسّنة، خرائط/مراحل، فيزياء قيادة، تحسين LOD، واختبارات على أجهزة أندرويد مختلفة.
